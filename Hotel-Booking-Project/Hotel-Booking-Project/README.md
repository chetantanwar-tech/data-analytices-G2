# Hotel Booking Project

## Files
1. cleaned_hotel_bookings.csv - Raw + cleaned hotel booking dataset
2. bookings.ipynb - Data loading + basic exploration
3. EDA Hotel Booking.ipynb - Exploratory data analysis + visualizations  
4. Hotel Booking SQL.ipynb - SQL queries on hotel data
5. Hotel Booking SQL.txt - SQL script notes
6. hotel bookings.pbix - Power BI dashboard

## Goal
Analyze hotel booking data for cancellation patterns, lead time, and revenue insights.
