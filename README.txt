==================================================
OMNICHANNEL RETAIL SALES & INVENTORY ANALYTICS
==================================================

Project Overview:
This project analyzes online and offline retail sales data
to generate business insights using Python, PostgreSQL,
and Power BI dashboard.

Objectives:
- Analyze sales performance
- Compare online vs offline channels
- Track inventory and product demand
- Study customer and city-wise sales trends

Technologies Used:
- Python
- Pandas
- PostgreSQL
- Jupyter Notebook
- Microsoft Power BI
- GitHub

Dataset Details:
- 500 retail transactions
- Year: 2025
- 6 Cities
- 3 Product Categories
- Online and Offline channels

Key Features:
- Sales trend analysis
- Channel comparison
- City-wise revenue analysis
- Customer segment analysis
- Inventory insights
- Interactive dashboard

Project Workflow:
1. Data Collection
2. Data Cleaning
3. Feature Engineering
4. Data Analysis
5. SQL Analytics
6. Power BI Visualization

Folder Structure:
data/          -> Dataset files
notebooks/     -> Python analysis
sql/           -> SQL queries
dashboard/     -> Power BI files
reports/       -> Project reports

Future Enhancements:
- AI based sales forecasting
- Real-time analytics
- Cloud deployment
