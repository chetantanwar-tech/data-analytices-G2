Omnichannel Sales Data Analytics Project

📌 Project Overview

This project focuses on analyzing omnichannel retail sales data using SQL, Python, and Power BI. The goal is to extract meaningful business insights, identify trends, and support data-driven decision-making.

---

🛠️ Tools & Technologies Used

- Python (Pandas, Matplotlib, Seaborn)
- PostgreSQL (SQL queries for data analysis)
- Power BI (Interactive dashboard)
- Jupyter Notebook
- CSV / Excel Data Sources

---

📂 Project Structure

- "Data Analytics project.pdf" → Project documentation
- "omnichannel_retail.ipynb" → Omnichannel python analysis
- "omnichannel_SQL.ipynb" → SQL queries executed in notebook
- "omnichannel_queries.sql" → Business SQL queries
- "omnichannel_Sales.csv" → Main dataset
- "omnichannel_BI.pbix" → Power BI dashboard file
- "omnichannel.xltx" → Excel template
---

🔍 Key Objectives

- Analyze sales performance across different channels
- Identify top-performing products and regions
- Understand customer purchasing behavior
- Compare online vs offline sales trends
- Generate actionable business insights

---

📈 Key Insights

- Sales show variation across channels, with certain channels contributing higher revenue.
- Seasonal trends impact overall sales performance.
- A small group of products contributes significantly to total revenue.
- Customer purchase patterns indicate repeat buying behavior in specific segments.

---

🧠 SQL Analysis

- Aggregations (SUM, AVG, COUNT)
- Joins across datasets
- Group By & Filtering
- Business queries for KPIs like revenue, orders, and customer segmentation

---

📊 Power BI Dashboard

The dashboard provides:

- Sales overview
- Channel-wise performance
- Region-wise insights
- Trend analysis with interactive filters

---

▶️ How to Run the Project

1. Load the dataset (".csv") into PostgreSQL
2. Run SQL queries from ".sql" files
3. Open Jupyter notebooks to perform Python analysis
4. Open ".pbix" file in Power BI to view dashboard

---

🎯 Conclusion

This project demonstrates how combining SQL, Python, and visualization tools can transform raw data into actionable insights for business growth.
